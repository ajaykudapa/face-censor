# Face Censor 🔒🖼️

A Python project to automatically detect faces in images or videos and censor them (e.g., blur or pixelate faces) using OpenCV.

---

## 🚀 Features
- Detect faces in images and videos
- Apply censorship (blur / pixelation)
- CLI usage or script integration
- Simple and customizable Python codebase

---

## 🖥️ Tech Stack
- **Python 3.x**
- **OpenCV** for computer vision
